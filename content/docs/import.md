# Importing from a spreadsheet

Already have your clients, products or services in a spreadsheet? Bring them in from a CSV or Excel file instead of typing each one by hand.

## How to import

1. Go to the **Clients**, **Products** or **Services** page and click **Import**.
2. Upload a `.csv` or `.xlsx` file (up to around 500 rows at a time).
3. The app automatically matches your spreadsheet columns to the right fields. Check the matches and adjust any that aren't quite right.
4. Preview the rows to make sure everything looks correct.
5. Click **Import**.

When it finishes, you'll get a summary showing how many records were:

- **Created** — added successfully
- **Skipped** — duplicates that already exist
- **Errors** — rows that couldn't be added, each with the reason why

## Which columns to include

Use clear column names so they match automatically:

- **Clients** — name, phone, email, company, address
- **Products** — name, SKU, price, stock
- **Services** — name, price, category

## Tips

> A header row with clear column names (Name, Phone, Price…) maps automatically — no manual matching needed.

> Duplicates are skipped based on a matching phone, SKU or name, so it's safe to re-import a file. Only the new rows get added.
