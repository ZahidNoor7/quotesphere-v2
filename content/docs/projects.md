# Projects

A project gathers all the work, money and documents for a single job or client engagement into one place, so nothing gets scattered.

## Create a project

1. Go to **Projects** and click **+ New project**.
2. Give it a **name** and choose the **client** it's for.
3. Add any optional details:
   - A **description** of the work
   - A **status** — pending, in progress, on hold, complete or cancelled
   - **Start** and **due** dates
   - A **budget**
   - A **progress %** to show how far along you are
4. Save. Each project is given its own number automatically, like **PRJ-00001**.

## What a project holds

Open any project to see everything about that job together:

- **Milestones** — the key stages or deliverables
- **Notes** — anything worth remembering
- **Time entries** — the hours spent on the work

You can also link your **invoices**, **quotations** and **expenses** to the project. Once linked, the project page shows them all in one view, along with running totals — so you see what's been quoted, billed and spent without jumping between screens.

> Use a project to keep an eye on **budget vs. actual spend** and how much you've invoiced on a big job. It's the simplest way to tell, at a glance, whether the work is on track and making money.
